# Sovereign Memory launch-site draft

This is a local-only, buildless HTML/CSS/JavaScript draft for the future
Sovereign Memory launch site. It has no analytics, external fonts, external
images, payment integration or download artifacts.

## Preview locally

From this directory:

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173>.
