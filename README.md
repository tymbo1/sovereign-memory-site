# Sovereign Memory launch-site draft

This is a buildless HTML/CSS/JavaScript draft for the Sovereign Memory launch
site. It has no analytics, external fonts, external images, payment integration
or download artifacts. All product demonstrations use synthetic content and do
not connect to a vault or an AI provider.

## Preview locally

From this directory:

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173>.
