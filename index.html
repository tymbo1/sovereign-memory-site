Questions worth answering

Plain language first. Technical detail when you want it.

What is Sovereign Memory?

A local-first memory layer for imported AI conversations. It is designed to preserve source history, make it searchable and let you choose which context a compatible model receives.

Is my archive uploaded to a server?

The product is being built around local encrypted storage. The public alpha site has no archive upload, analytics or external scripts.

Can I use local AI models?

Local model workflows are part of the owner-operated alpha. Public support details will be published with the release matrix.

Can a model see my entire archive?

No model should receive the entire vault by default. Context is selected, scoped and previewed according to the destination and the user’s approval.

What happens if I forget my vault password?

Password recovery is still an explicit product-design and security decision. The public release will document the supported recovery model clearly.

Is the software available now?

Not for public download. Sovereign Memory is currently an owner-operated alpha, with packaging and release validation still underway.
